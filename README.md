## 個人情報の扱い
- 外部のサイト（Googleなど）には接続しない。文字のデザインもこのサイトから配信している。
- 名前やアンケートの答えは、各スマホの中（localStorage）だけに保存する。トップページのボタンで全部消せる。
- 身内クイズ・秘密ミッションは、サーバーを使わず「コード」をLINEで送り合う。
- 早当てお絵かきと、みんなで対戦だけは、無料の公開MQTTサーバー（HiveMQ → EMQX → Eclipse の順）で中継する。
  - 中身はすべて端末の中で AES-GCM（256bit）で暗号化してから送る。
  - 鍵は幹事の端末で部屋ごとに作り、部屋のリンクの「#」より後ろにだけ入れる（サーバーにもGitHubにも届かない）。
  - サーバー上の置き場所の名前も鍵から作る。部屋の番号やゲーム名、名前はサーバーに出ない。
  - 幹事が部屋を閉じるとサーバーの保存分を消す。閉じ忘れても12時間で自動で消える（MQTT 5 の有効期限）。
  - 何を送受信したかは、ゲーム内の「通信ログ」で見られる（記録は端末のメモリだけ）。
- みんなで対戦の通信のしくみ
  - 置き場所は5つ（参加者・進行・みんなへ・幹事へ・動きの速報）。幹事以外は「幹事へ」を受け取らない。
  - 幹事のスマホが進行役。ゲームの判定（綱の位置・点数・爆発の時刻など）は幹事のスマホだけで計算する。爆弾の爆発時刻はほかのスマホにも送らない。
  - 時計あわせ：参加者は幹事のスマホと時刻を合わせて、同時スタートや順位の判定に使う。往復の時間は待合室に表示する。
  - センサー（傾き・動き）の値そのものは送らない。送るのは「振った回数」「刺さった場所」「進んだ歩数」などの結果だけ。
  - エアホッケーのパックと、カートの位置は、それぞれのスマホが自分で計算して1秒に10〜20回送る（これも暗号化）。当たり判定は「当てられた側」のスマホがする。

## 公開のしかた（GitHub Pages）
1. GitHubで新しいリポジトリを作る（Public）。
2. このフォルダの中身をそのままアップロードする。
3. Settings → Pages → Branch を `main` / `/(root)` にして Save。
4. 数分後に `https://<ユーザー名>.github.io/<リポジトリ名>/` で開ける。
