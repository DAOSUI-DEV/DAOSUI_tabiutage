# 旅宴ゲーム

旅先の宴会で遊ぶ、iPhoneのブラウザだけで動く4つのゲーム。

| ファイル | ゲーム | 遊び方 |
|---|---|---|
| index.html | トップページ | 4つのゲームへのリンク |
| quiz.html | 身内クイズ | 全員が自分のスマホ |
| mission.html | 秘密ミッション | 全員が自分のスマホ |
| oekaki.html | お絵かき伝言 | スマホ1台を回す |
| beer.html | こぼすなビール | スマホ1台を回す |
| sw.js | オフライン用 | 一度ひらけば電波なしでも動く |

## 公開のしかた（GitHub Pages）
1. GitHubで新しいリポジトリを作る（Public）。
2. このフォルダの中身をそのままアップロードする。
3. Settings → Pages → Branch を `main` / `/(root)` にして Save。
4. 数分後に `https://<ユーザー名>.github.io/<リポジトリ名>/` で開ける。

サーバーやデータベースは使っていない。データは各スマホの中だけに保存され、
人と人のやりとりは「コード」をLINEで送り合う形になっている。
